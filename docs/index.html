シロアリボージョ（仮）
ルールとカード一覧

シロアリ側と防除業者側に分かれて、コンピューター（CPU）と戦うカードゲームです。シロアリ側は家を食い進めて完全に侵食することを、防除業者側はそれを守りきることをめざします。

1. はじめに知っておくことば

山札（やまふだ）
まだ引いていないカードの束です。陣営ごとに50枚あります。
手札（てふだ）
いま自分の手元にあって、使えるカードです。
捨て札（すてふだ）
使い終わったカードや、捨てたカードを置く場所です。山札が尽きても、捨て札を混ぜ直して使うことはありません。
ターン
自分の番のことです。シロアリ側と防除業者側が交互に行います。
コスト（行動力）
カードを使うときに払うポイントのようなものです。毎ターンのはじめに3になり、余っても次のターンには持ち越せません。
ポイント
家の中の「場所」のことです。浴室、キッチン、床下など全部で8か所あり、カードはこの場所に置きます（「得点」ではありません）。
完全侵食（かんぜんしんしょく）
1つのポイントにシロアリカードが3枚重なった状態です。そのポイントはシロアリに食い尽くされて「潰れた」ことになり、以後どのカードの対象にもなりません。
除去（じょきょ）
場に置かれたシロアリカードを取り除くことです。
陣営（じんえい）
シロアリ側か、防除業者側かのことです。

2. 勝ち方

シロアリ側の勝ち

8か所のうち5か所を完全侵食する

8か所の過半数（5か所）を完全侵食すれば勝ちです。

防除業者側の勝ち

シロアリの山札がなくなるまで守りきる

シロアリ側の山札（50枚）が尽きるまで、5か所の完全侵食を許さなければ勝ちです。

3. 対戦の流れと1ターンの流れ

対戦の準備

  • プレイヤーはシロアリ側か防除業者側を選び、CPUと対戦します。
  • 山札は陣営ごとに別々です（シロアリ山札50枚・防除山札50枚）。「中立」のカードは両方の山札に入ります。
  • 最初の手札は5枚です。
  • 先攻・後攻はじゃんけん、またはコイントスで決め、そのあとは交互にターンを行います。

1ターンの流れ

  1. ターン開始：行動力が3になる
    余っていた行動力は持ち越しません。このとき山札からカードを引くことはありません。
  2. カードを使う
    行動力が足りる限り、何枚でも使えます。カードごとに決まったコストを行動力から払います。ただしシロアリカードは、1ターンに同じポイントへ1枚までです。
  3. 手詰まり防止（1枚もカードを使わなかったときだけ）
    補充の前に、手札を1枚捨てて、山札から1枚引くことができます（するかどうかは自由です）。
  4. ターンの終わりに手札を補充する
    手札が5枚になるまで、自分の山札から引きます。すでに5枚を超えていれば引きません。
  5. 手札上限のチェック
    手札の上限は7枚です。ターンの終わりに8枚以上あるときは、7枚になるまで好きなカードを捨てます。捨てたカードは捨て札になり、山札には戻りません。

4. 家の8か所と、置けるシロアリ

この家は、ふだんは換気や防湿が効いていて乾いている設定です。ヤマトシロアリは水を運べないため、水回りにしか置けません。

ポイント状態置けるシロアリ
浴室・洗面所水回りヤマトイエ
キッチン水回りヤマトイエ
床下・土台乾燥箇所イエ
玄関・框（かまち）乾燥箇所イエ
庭の枯れ木乾燥箇所（特殊）イエ
ウッドデッキ乾燥箇所イエ
梁（はり）・柱上部イエカンザイ
屋根裏・天井上部イエカンザイ

この対応表は、ご確認いただく前提のものです（第8章参照）。

特殊なポイント：庭の枯れ木

  • 完全侵食（倒れる）には、シロアリカードが4枚必要です（ほかのポイントは3枚）。
  • 枯れ木が倒れると、全ポイントの完全侵食に必要な枚数が3枚から2枚に減ります。

5. シロアリカードの仕組み

シロアリカードは「種類」と「カースト（役割）」の組み合わせでできています。たとえば「ヤマトシロアリの職アリ」「イエシロアリの兵アリ」です。

種類：置ける場所が決まる

ヤマトイエカンザイ

どのポイントに置けるかは、第4章の表のとおりです。

カースト：効果が決まる

職アリ・兵アリ・羽アリ・女王アリ

どのカーストも、ポイントでは1枚分として数えます。

羽アリと女王アリ

  • 女王アリは山札に入っていません。種類ごとに1枚ずつ、別に用意されています。
  • 羽アリを置くと、次の自分のターン開始時に女王アリと入れ替わります。使った羽アリは捨て札へ移ります。
  • 女王アリになったときに、同じ種類の職アリを山札から2枚、手札に加えます。
  • 女王アリになる前に羽アリを駆除されると、女王アリにはなりません。

兵アリ

  • 兵アリがいるポイントへの薬剤散布を、1回無効にします（兵アリ1枚につき1回）。
  • ベイト工法は防げません。

7. 細かいルール（Q&A）

カードの使い方

1ターンに何枚までカードを使えますか。
行動力が足りる限り、枚数の上限はありません。
同じポイントに何枚でも置けますか。
シロアリカードは、1ターンに同じポイントへ1枚までです。防除・駆除・イベント・中立のカードにはこの制限はありません。たとえば、薬剤散布を続けて使うことや、薬剤散布・バリア工法とベイト工法を一緒に使うことができます。
偵察や妨害は、いつでも使えますか。
相手の手札が1枚もないときは使えません。
予知はどう使いますか。
自分の山札の上3枚を見て、1枚を手札に加えます。残りの2枚は、好きな順番で山札の下に置きます。
イベントカードや中立カードは、いつ使いますか。
ほかのカードと同じく手札に入ります。持ち主が、自分のターン中の好きなタイミングで使います。

カード効果の共通ルール

「次の自分のターンまで」続く効果は、いつ切れますか。
そのカードを使った人の、次のターンが始まるときに切れます。
完全侵食されたポイントに、カードは使えますか。
使えません。完全侵食されたポイントは、すべてのカードの対象外です。
山札から特定のカードを手札に加える効果で、そのカードが山札に残っていないときは。
何も起こりません（空振りになります）。
ベイト工法はいつ効きますか。
置いてから2回目の、自分のターンが始まるときに効きます。そのポイントにいるヤマトシロアリとイエシロアリをすべて取り除きます。カンザイシロアリは対象外です。同じポイントに重ねて置くことはできません（この点は仮の扱いです）。
バリア工法はどのくらい続きますか。
置いてから3ターンの間、そのポイントにシロアリカードを置けなくします。「3ターン」の数え方は、第8章で確認中です。
大量発生を使うとどうなりますか。
シロアリ側の次のターンが始まるときまで、そのポイントに防除・駆除カードを置けなくなります。シロアリ側は、そのポイントにカードを置けます。

ご確認いただきたい点

  • 防除・駆除カードの効果、およびシロアリの種類と工法の対応
    バリア工法・薬剤散布・ベイト工法の効果が、シロアリの生態に照らして妥当かをご確認いただきたいです。
  • 置ける場所の対応表
    第4章の表（どのシロアリがどのポイントに置けるか）が、実際の生態と合っているかをご確認いただきたいです。

実装にあたって仮に決めている点

  • バリア工法の「3ターン」は、防除側の自分のターン3回分と数える仮定です（シロアリ側の手番を3回ふさぎ、防除側の3回後のターン開始時に切れます）。
  • 同じ種類の女王アリがすでに場にいるときに、2枚目の羽アリを置いた場合は、女王アリにならず羽アリのまま残る仮定です。
  • カードを使わずにターンを終え続けると、山札が減らず対戦が終わりません。その安全装置として、通算1000ターンで引き分けとする仮定です。
